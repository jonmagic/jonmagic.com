Clawdia is a private personal assistant used only by its owner. Its Gmail integration processes Gmail metadata and message content only when needed to fulfill my explicit requests.

The integration supports:

- searching messages
- reading a message I select
- creating a draft for my review

It does not expose email sending, deletion, archiving, label changes, or attachment downloads.

OAuth client credentials, refresh tokens, and access tokens stay on the private host where Clawdia runs. They are not exposed through this website.

Gmail data processed by Clawdia is not sold, used for advertising, or provided to third parties.

Return to the [Clawdia homepage](/clawdia/) or read the [terms of use](/clawdia/terms/).
